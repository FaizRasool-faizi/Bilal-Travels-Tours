## 📌 Project Overview

This platform serves as the digital front door and operational backbone for **Bilal Travels & Tours**, delivering:
1. **Public Travel Marketing Portal:** High-impact destination showcases, dynamic holiday tour packages with day-wise itineraries and PKR pricing, country-specific visa consultancy guides, and dedicated sacred Umrah journey packages.
2. **Customer Journey Portal ("My Journey"):** Personal traveller dashboard with live milestone steppers (`Application Submitted` → `Visa Approved` → `Travel` → `Completed`) and secure document vault for tickets and vouchers.
3. **Agency Management Back-Office:** Role-based administrative dashboard for travel consultants, operations teams, and editors to manage leads, visa pipelines, package CMS, and consent-verified traveller stories.
